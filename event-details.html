WORKSHOP DETAILS

Introduction to Python

An introductory workshop covering the basic concepts of Python programming.

About This Event

This workshop introduces students to the basic concepts of Python programming. It is suitable for students who have little or no previous programming experience.

Participants will follow simple examples and complete short programming exercises during the session.

Workshop Topics

  • Introduction to Python and its uses
  • Variables and basic data types
  • Input and output statements
  • Conditional statements
  • Loops and simple exercises

Who Can Attend?

The workshop is open to university students who are interested in learning the basics of programming and data science.

What to Bring

Participants should bring a laptop with Python and Visual Studio Code installed.
